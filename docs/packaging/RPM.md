# RPM notes

This note records the Batch 10 RPM checks that are specific to Fedora-style
packaging.

## RUNPATH policy

The modules that link Evolution private libraries must keep
`pkg-config --variable=privlibdir evolution-shell-3.0` in their RUNPATH.

`ci/rpm.sh` enforces this after the RPM build for:

- `libjmap_backend_book_module.so`
- `libjmap_backend_cal_module.so`
- `libjmap_backend_collection_module.so`
- `libjmap_config_module.so`

The script fails when a required module has no RUNPATH, or when the RUNPATH
does not include Evolution's private library directory.

## Explicit `Requires` policy

No explicit non-ELF runtime `Requires` are configured in
`cmake/PackagingRpm.cmake`.

Reason:

- The package payload is shared modules and data files.
- The package does not ship RPM scriptlets.
- Runtime ELF dependencies are generated by RPM automatically.

`ci/rpm.sh` validates this by failing if any produced RPM contains scriptlets,
which would require review of explicit non-ELF `Requires` ownership.
